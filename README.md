# Приватна стоматологічна клініка — концептуальна модель даних

Цей проєкт описує предметну область інформаційної системи приватної стоматологічної клініки: облік пацієнтів, лікарів та їхніх спеціальностей, кабінетів прийому, переліку медичних послуг, записів на прийом (візитів) та рахунків на оплату. Призначення системи — автоматизувати запис пацієнтів на прийом, планувати завантаження лікарів і кабінетів, фіксувати перелік наданих під час візиту послуг та контролювати виставлення й оплату рахунків.

Базовий бізнес-процес: пацієнт звертається до клініки й **записується на прийом** до лікаря потрібної спеціальності (обирається дата, час і кабінет) → у призначений час відбувається **прийом**, під час якого лікар надає одну або декілька **послуг** → за результатами прийому клініка формує **рахунок на оплату**, який пацієнт оплачує повністю чи частково. Документи `spec.md` та діаграма `er-diagram.mmd` деталізують сутності, їхні атрибути та зв'язки, що лежать в основі цього процесу.
